# Proyecto Sprint 8: Urban Grocers

---
En este proyecto se están realizando pruebas para el servicio Urban Grocers por medio de su API, manejando diversas posibilidades a la hora de la creacion de una cuenta y de los kits.

---
## Requisitos
Para utilizar correctamente este proyecto se es necesario descargar:
- Libreria requests.
- Pytest.

Ambas son posibles de ser descargadas mediante este comando: ```pip install requests pytest```.

---
Para correr las pruebas se puede hacer mediante el comando: ```"python pytest -s .\create_kit_name_kit_test.py"``` desde la terminal o directamente creando una configuracion en "Run/Debug Configuration" y seleccionar la opcion "python pytest".

La documentación de la API se consultó en apiDoc.
> **Nota:** Es necesario aclarar que algunas pruebas están destinadas a fallar, si aparece el mensaje "FAILED" no es necesariamente un error de codigo, es un bug.
